# صوتك · Sotak

> مكالمات صوتية مباشرة بين جهازين أندرويد عبر **Wi-Fi Direct** — بدون إنترنت، بدون سيرفر، وبدون أي حساب.

<div align="center">

`Kotlin` · `Jetpack Compose` · `Wi-Fi Direct (WifiP2pManager)` · `C++ / NDK` · `Opus` · `UDP` · `Foreground Service`

</div>

---

## لمحة سريعة

**صوتك** تطبيق أندرويد حديث وصغير الحجم يتيح لك التحدث مع أي جهاز قريب دون الحاجة إلى شبكة إنترنت أو شبكة خلوية. يتم إنشاء رابط مباشر بين الجهازين عبر Wi-Fi Direct، ثم يُنقل الصوت كحزم UDP مضغوطة بترميز Opus.

-  **بدون إنترنت** — يعمل حتى لو لم تكن متصلًا بأي شبكة.
-  **بدون سيرفر** — الجهازان يتحدثان مباشرة.
-  **مكالمات واردة** — الجهاز الآخر **يرن** فعليًا عند وصول مكالمة، مع إشعار ملء الشاشة وأزرار رد/رفض.
-  **صوت نقي بلا تقطيع** — مخزن اهتزاز (Jitter Buffer) في C++ يعالج تأخر وفقدان الحزم.
-  **حجم صغير** — R8 + تقليص الموارد + معماريات ARM فقط.
-  **واجهة عصرية** — Jetpack Compose بتصميم داكن مستقبلي.

## كيف يعمل؟ (المعمارية)

```
┌─────────────────────────── جهاز (Group Owner / مستضيف) ───────────────────────────┐
│                                                                                   │
│  الميكروفون ──▶ AudioRecord ──▶ [C++ Opus Encoder] ──▶ UDP Packet ──┐             │
│                                                                      │             │
│  السماعة ◀── AudioTrack ◀── [C++ Jitter Buffer + Opus Decoder] ◀── UDP Socket ◀─┤
│                                                                      ▲             │
│                        TCP Control (8988) : RING / ACCEPT / DECLINE ─┘             │
└───────────────────────────────────────────────────────────────────────────────────┘
                ▲                                    │
                │        رابط Wi-Fi Direct مباشر      │
                ▼                                    ▼
┌─────────────────────────── جهاز (Client / زائر) ──────────────────────────────────┐
│              نفس المسار: التقاط ➜ ترميز ➜ إرسال ➜ استقبال ➜ فك ترميز ➜ تشغيل        │
└───────────────────────────────────────────────────────────────────────────────────┘
```

### المسار الكامل للمكالمة

1. **الاستماع الدائم** — خدمة أمامية (`SotakService`) تُبقي التطبيق حيًّا وجاهزًا لاستقبال المكالمات حتى وهو في الخلفية.
2. **الاكتشاف والاتصال** — `WifiDirectManager` يبحث عن الأجهزة القريبة، وعند اختيار جهاز يبدأ اتصال Wi-Fi Direct (WPS PBC). أحد الجهازين يصبح *Group Owner*.
3. **المصافحة والإشارات** — قناة تحكم صغيرة عبر **TCP على المنفذ 8988**:
   ```
   المتّصل  ──▶  "RING <اسمي>"
   المستلِم ──▶  "ACCEPT <اسمي>"   أو   "DECLINE"
   ثم: طرف TCP ──▶ "PORT <رقم منفذ UDP>"   /   الطرف الآخر ──▶ "READY"
   ```
4. **الرنين** — عند وصول `RING` يرنّ الجهاز فعليًا: نغمة الرنين الافتراضية للنظام + اهتزاز + إشعار عالي الأهمية بـ**ملء الشاشة** يعرض زرّي **رد** و**رفض** (يعمل حتى من شاشة القفل).
5. **التقاط الصوت** — `AudioRecord` بمعدل 48kHz أحادي مع تفعيل إلغاء الصدى (AEC) وكبح الضوضاء (NS).
6. **الترميز (C++)** — كل 20ms تُرمَّز حزمة PCM إلى حزمة Opus صغيرة (~80 بايت) بترميز `OPUS_APPLICATION_VOIP`.
7. **النقل** — الحزم تُرسل عبر **UDP على المنفذ 8989** بترويسة تحتوي رقم التسلسل.
8. **مخزن الاهتزاز (C++)** — الحزم الواردة تُرتَّب حسب تسلسلها؛ الحزم المتأخرة تُصلح، والمفقودة تُعوَّض بتقنية *Packet Loss Concealment* من Opus.
9. **التشغيل** — الإطارات المُفكَّكة تُشغَّل عبر `AudioTrack` باحتياطي ~200ms لتفادي الفرقعات.

> لماذا UDP وليس TCP للصوت؟ لأن TCP يعيد إرسال الحزم المفقودة ويوقف كل ما بعدها (Head-of-Line Blocking)، وهو ما يسبب التقطيع والثقل في الصوت الحيّ. UDP يتجنب ذلك تمامًا — بينما نُبقي TCP للمصافحة فقط حيث نريد الموثوقية.

## هيكل المشروع

```
sotak/
├── app/
│   ├── build.gradle.kts          # إعدادات الوحدة + NDK/CMake
│   ├── proguard-rules.pro        # حماية طبقة JNI + تقليص الحجم
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── cpp/                  # ❱❱ محرّك الصوت الأصلي (C++)
│       │   ├── CMakeLists.txt        # يجلب Opus تلقائيًا وقت البناء
│       │   ├── audio_engine.h/.cpp   # الغلاف حول Opus (ترميز/فك ترميز)
│       │   ├── jitter_buffer.h/.cpp  # إعادة الترتيب ومعالجة الفقدان
│       │   └── native_bridge.cpp     # جسر JNI مع Kotlin
│       ├── java/com/sotak/app/
│       │   ├── MainActivity.kt       # نقطة الدخول (Compose) + الظهور فوق شاشة القفل
│       │   ├── SotakApp.kt           # التوجيه بين الشاشات + الأذونات
│       │   ├── SotakApplication.kt   # يملك المنسّق الوحيد للتطبيق
│       │   ├── MainViewModel.kt      # واجهة رفيعة فوق CallCoordinator
│       │   ├── wifi/                 # طبقة Wi-Fi Direct
│       │   ├── net/                  # CallChannel: مصافحة RING/ACCEPT + نقل UDP
│       │   ├── audio/                # جسر JNI + التقاط/تشغيل
│       │   ├── call/                 # CallCoordinator, CallSession, Ringer, Notifier
│       │   ├── service/              # SotakService: خدمة أمامية دائمة
│       │   └── ui/                   # الثيم والمكوّنات والشاشات
│       └── res/                      # الأيقونة والثيم والنصوص
├── build.gradle.kts
├── settings.gradle.kts
└── gradle/wrapper/
```

### المكوّنات الأساسية

| المكوّن | الدور |
|---|---|
| `CallCoordinator` | عقل التطبيق: يملك Wi-Fi Direct والإشارات والصوت والرنين والإشعارات |
| `CallChannel` | مصافحة RING/ACCEPT/DECLINE على TCP + نقل الصوت على UDP |
| `CallSession` | محرّك الصوت (التقاط ← ترميز ← إرسال / استقبال ← فك ترميز ← تشغيل) |
| `Ringer` | نغمة رنين النظام + اهتزاز (بدون أي ملفات صوتية مرفقة) |
| `IncomingCallNotifier` | إشعار ملء الشاشة + أزرار رد/رفض + إشعار الخدمة الدائم |
| `SotakService` | خدمة أمامية تُبقي التطبيق جاهزًا لاستقبال المكالمات في الخلفية |

## التشغيل والبناء

### المتطلبات

- Android Studio **Ladybug (2024.2)** أو أحدث
- Android SDK 34 + **NDK** + **CMake 3.22.1**
- اتصال إنترنت **مرة واحدة فقط أثناء البناء** (ليجلب Opus عبر CMake)

### الخطوات

```bash
# 1) استنسخ المستودع
git clone https://github.com/GoldYemen/YourVoice.git
cd YourVoice

# 2) إنشاء ملف gradle wrapper (مرة واحدة)
gradle wrapper --gradle-version 8.7

# 3) البناء
./gradlew assembleDebug        # نسخة تجريبية
./gradlew assembleRelease      # نسخة مُصغَّرة (تحتاج توقيع)
```

أو ببساطة: افتح المجلد في **Android Studio** واضغط Run — سيتولى البناء الأصلي والحزمة تلقائيًا.

> أول بناء قد يستغرق بضع دقائق لأنه يترجم مكتبة Opus من المصدر لمعماريتين (ARM32/ARM64). البناءات التالية تكون سريعة بفضل التخزين المؤقت.

## طريقة الاستخدام

### لإجراء مكالمة (الطرف المُتّصل)
1. شغّل **الواي فاي** على الجهازين (بدون الحاجة لشبكة إنترنت).
2. امنح الأذونات: الميكروفون، الأجهزة القريبة/الموقع، والإشعارات.
3. اضغط **ابحث**، ثم اختر الجهاز من القائمة واضغط زر الاتصال → ستظهر شاشة **«يرن… في انتظار الرد»**.

### لاستقبال مكالمة (الطرف الآخر)
- ما على الطرف الآخر سوى أن يكون التطبيق مفتوحًا (أو في الخلفية) — سيُشغَّل تلقائيًا **إشعار «صوتك جاهز»** دائمی يبقيه متاحًا.
- عند وصول مكالمة: **يرن الجهاز + يهتز**، وتظهر شاشة ملء الشاشة بزرّي **رد** و**رفض** — تعمل حتى إن كان الهاتف مقفلًا.
- يمكن أيضًا الرد/الرفض مباشرة من الإشعار دون فتح التطبيق.

## أذونات التطبيق

| الإذن | السبب |
|---|---|
| `RECORD_AUDIO` | التقاط صوت المكالمة |
| `ACCESS_FINE_LOCATION` | مطلوب من النظام لاكتشاف أجهزة Wi-Fi Direct |
| `NEARBY_WIFI_DEVICES` (Android 13+) | بديل الموقع للأجهزة القريبة |
| `POST_NOTIFICATIONS` (Android 13+) | إظهار إشعار المكالمة الواردة |
| `VIBRATE` | اهتزاز الجهاز عند الرنين |
| `USE_FULL_SCREEN_INTENT` | إظهار شاشة المكالمة فوق شاشة القفل |
| `FOREGROUND_SERVICE*` | البقاء جاهزًا لاستقبال المكالمات في الخلفية |

> **ملاحظة Android 14+:** قد يحتاج مستخدم الجهاز لمنح صلاحية «ملء الشاشة» من **الإعدادات ← التطبيقات ← صوتك ← الإشعارات ← المكالمات الواردة** ليعمل الإشعار بملء الشاشة. بدونها سيظهر كإشعار بارز عادي مع الرنين والاهتزاز.
