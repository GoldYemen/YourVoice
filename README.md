# صوتك · Sotak

> مكالمات صوتية مباشرة بين جهازين أندرويد عبر **Wi-Fi Direct** — بدون إنترنت، بدون سيرفر، وبدون أي حساب.

<div align="center">

`Kotlin` · `Jetpack Compose` · `Wi-Fi Direct (WifiP2pManager)` · `C++ / NDK` · `Opus` · `UDP`

</div>

---

## لمحة سريعة

**صوتك** تطبيق أندرويد حديث وصغير الحجم يتيح لك التحدث مع أي جهاز قريب دون الحاجة إلى شبكة إنترنت أو شبكة خلوية. يتم إنشاء رابط مباشر بين الجهازين عبر Wi-Fi Direct، ثم يُنقل الصوت كحزم UDP مضغوطة بترميز Opus.

-  **بدون إنترنت** — يعمل حتى لو لم تكن متصلًا بأي شبكة.
-  **بدون سيرفر** — الجهازان يتحدثان مباشرة.
-  **صوت نقي بلا تقطيع** — مخزن اهتزاز (Jitter Buffer) في C++ يعالج تأخر وفقدان الحزم.
-  **حجم صغير** — R8 + تقليص الموارد + معماريات ARM فقط.
-  **واجهة عصرية** — Jetpack Compose بتصميم داكن مستقبلي.

## كيف يعمل؟ (المعمارية)

```
┌─────────────────────────── جهاز (Group Owner / مستضيف) ───────────────────────────┐
│                                                                                   │
│  الميكروفون ──▶ AudioRecord ──▶ [C++ Opus Encoder] ──▶ UDP Packet ──┐             │
│                                                                      │             │
│  السماعة ◀── AudioTrack ◀── [C++ Jitter Buffer + Opus Decoder] ◀── UDP Socket ◀─┤
│                                                                      ▲             │
│                                          TCP Control (8988) ──────────┘             │
└───────────────────────────────────────────────────────────────────────────────────┘
                ▲                                    │
                │        رابط Wi-Fi Direct مباشر      │
                ▼                                    ▼
┌─────────────────────────── جهاز (Client / زائر) ──────────────────────────────────┐
│              نفس المسار: التقاط ➜ ترميز ➜ إرسال ➜ استقبال ➜ فك ترميز ➜ تشغيل        │
└───────────────────────────────────────────────────────────────────────────────────┘
```

### المسار الكامل للصوت

1. **الاكتشاف والاتصال** — `WifiDirectManager` يبحث عن الأجهزة القريبة، وعند اختيار جهاز يبدأ اتصال Wi-Fi Direct (WPS PBC). أحد الجهازين يصبح *Group Owner*.
2. **المصافحة** — قناة تحكم صغيرة عبر **TCP على المنفذ 8988** تُبادل خلالها الأجهزة منفذ UDP الخاص بكل طرف.
3. **التقاط الصوت** — `AudioRecord` بمعدل 48kHz أحادي مع تفعيل إلغاء الصدى (AEC) وكبح الضوضاء (NS).
4. **الترميز (C++)** — كل 20ms تُرمَّز حزمة PCM إلى حزمة Opus صغيرة (~80 بايت) بترميز `OPUS_APPLICATION_VOIP`.
5. **النقل** — الحزم تُرسل عبر **UDP على المنفذ 8989** بترويسة تحتوي رقم التسلسل.
6. **مخزن الاهتزاز (C++)** — الحزم الواردة تُرتَّب حسب تسلسلها؛ الحزم المتأخرة تُصلح، والمفقودة تُعوَّض بتقنية *Packet Loss Concealment* من Opus.
7. **التشغيل** — الإطارات المُفكَّكة تُشغَّل عبر `AudioTrack` باحتياطي ~200ms لتفادي الفرقعات.

> لماذا UDP وليس TCP؟ لأن TCP يعيد إرسال الحزم المفقودة ويوقف كل ما بعدها (Head-of-Line Blocking)، وهو ما يسبب التقطيع والثقل في الصوت الحيّ. UDP يتجنب ذلك تمامًا.

## التشغيل والبناء

### المتطلبات

- Android Studio **Ladybug (2024.2)** أو أحدث
- Android SDK 34 + **NDK** + **CMake 3.22.1**
- اتصال إنترنت **مرة واحدة فقط أثناء البناء** (ليجلب Opus عبر CMake)

### الخطوات

```bash
# 1) استنسخ المستودع
git clone <رابط-المستودع>
cd sotak

# 2) إنشاء ملف gradle wrapper (مرة واحدة)
gradle wrapper --gradle-version 8.7

# 3) البناء
./gradlew assembleDebug        # نسخة تجريبية
./gradlew assembleRelease      # نسخة مُصغَّرة (تحتاج توقيع)
```

أو ببساطة: افتح المجلد في **Android Studio** واضغط Run — سيتولى البناء الأصلي والحزمة تلقائيًا.

> أول بناء قد يستغرق بضع دقائق لأنه يترجم مكتبة Opus من المصدر لمعماريتين (ARM32/ARM64). البناءات التالية تكون سريعة بفضل التخزين المؤقت.

## ملاحظات الاستخدام

- يجب تشغيل **الواي فاي** على الجهازين (بدون الحاجة لشبكة إنترنت).
- امنح التطبيق أذونات **الميكروفون** و**الأجهزة القريبة / الموقع**.
- اضغط **ابحث** على الجهاز الأول، ثم اختر الجهاز الثاني من القائمة واضغط **الاتصال**.
- لم يُضف بعد طلب الاتصال بين الطرفين؛ الطرف الذي يبدأ الاتصال هو من يضغط زر الاتصال.
